# Åk!

Integritetspolicy och supportsida för appen Åk!, publicerade med GitHub Pages:
https://henrikhedvall-design.github.io/ak-app/

Källan ligger i det privata repot skidappen (mappen `docs/`). Ändra där först och kopiera hit.

Adminsidan finns på https://henrikhedvall-design.github.io/ak-app/admin/ (mappen `admin/`). Källan är `admin/` i skidappen.
Sidan innehåller bara serverns publika nyckel. Bara inloggade admins (ADMIN_EMAILS) kommer åt något, det kontrolleras på servern.
